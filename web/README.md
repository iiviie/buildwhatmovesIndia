# Sahi Return web application

This directory contains the Sites-compatible Sahi Return prototype. Read the repository [README](../README.md) for setup, validation, disclosures, and the implemented citizen journey.

## Commands

```bash
npm ci
npm run dev
npm run lint
npm test
npm run build
```

The application stores only the synthetic demo draft in browser local storage. It has no runtime database, login, OpenAI API call, payment, or government integration.
